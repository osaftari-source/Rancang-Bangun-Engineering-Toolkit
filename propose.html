To evaluate an idea, please provide the work process, required inputs, expected outputs, calculation basis or references, and at least one validation example where available.

Minimum Information Required

01Tool Name & Discipline

Name the proposed tool and applicable discipline.

02Problem & Workflow

Describe the recurring task and how it is currently performed.

03Required Inputs

List inputs, units, data sources, defaults, or selectable options.

04Expected Outputs

State the calculation results or summaries needed by users.

05Basis & References

Provide formula, standard, datasheet, Excel, or reference table.

06Validation Example

Attach a verified calculation case where possible.

Initial Submission Workflow

  1. Download the example proposal form.
  2. Replace the blue example text with the proposed tool information.
  3. Attach references or verified calculation examples, where available.
  4. Submit the completed form to the Toolkit developer for evaluation and potential inclusion in the roadmap.

An online submission workflow can be added in a future phase if proposal collection becomes routine.
